# PhysioTrack

A modern physiotherapy practice management system for tracking patient care from assessment to discharge.

## Features

- Patient management
- Clinical documentation
- Treatment tracking
- Progress monitoring
- Home exercise programs
- Therapist dashboard

## Tech Stack

Frontend:
- React
- Tailwind CSS
- React Router

Backend:
- Supabase

## Installation

Clone the repository:

git clone https://github.com/bigamaks/PhysioTrack.git

Install dependencies:

npm install

Run development server:

npm run dev
